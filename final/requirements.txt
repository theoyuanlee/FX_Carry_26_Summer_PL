# Five packages. This is the complete runtime dependency of everything in
# final/: the engine, the strategy, the verdict table, the tests and
# reproduce.py. Derived from the repo-wide requirements.txt by keeping only what
# this package imports, verified by grep rather than by memory.
#
# Python 3.13 (developed against 3.13.5).
#
#     pip install -r final/requirements.txt
#     python final/reproduce.py
#
# Deliberately NOT here, and each absence is a decision:
#   matplotlib / seaborn  -- nothing in final/ plots. The figures live in the
#                            research folder's decks and notebooks
#   scikit-learn          -- imported only by the tail-event forecast, which is
#                            a REJECTED null (VERDICTS.md). Its evidence CSVs
#                            ship; its code does not, because it is not part of
#                            the strategy
#   openpyxl              -- the Bloomberg xlsx supplement was already converted
#                            to parquet upstream; final/ reads no Excel
#   jupyter / ipykernel   -- no notebooks in this package by design
#   xbbg / blpapi         -- a Bloomberg terminal is needed only to REFRESH the
#                            data. data/raw/ is committed, so reproducing
#                            anything here needs no terminal and no entitlement
