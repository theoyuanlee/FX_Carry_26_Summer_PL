# `proposal/` — the original mandate

The two documents the project started from, kept so the delivered work can be read against what was
actually asked for.

| File | What it is |
|---|---|
| `Project Lab - Bank of America (FX Carry Strategy) Proposal.pdf` | The Project Lab proposal as issued — the scope, the desk context (Corporate Treasury / Global Funding), and the deliverable |
| `FX_Carry_Intro.pdf` | The introductory briefing on FX carry given at the start of the engagement |

**The research question, as posed:** *can a traditional FX carry strategy be improved by dynamically
adjusting exposure using macroeconomic conditions, volatility and momentum?*

The answer, and the evidence for it, is [`../final/`](../final/). The short version is **no, not in
any way that survives costs and significance testing** — nine attempts to time or improve the premium
all failed. What did work was managing the tail rather than predicting the return. See
[`../final/VERDICTS.md`](../final/VERDICTS.md).
